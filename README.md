# 🧠 Smart RAG System

**Гибридный поиск по документам (BM25 + Векторный поиск) с поддержкой LLM**


## Описание

Система для умного поиска по документам, которая комбинирует:

- **BM25** — лексический поиск по ключевым словам
- **FAISS** — семантический поиск по смыслу
- **LLM** (Mistral/OpenAI) — генерация ответов
- **Cross-encoder** — переранжирование результатов
- **Мультимодальность** — извлечение текста из изображений (OCR)

## Возможности

| Функция | Описание |
|---------|----------|
| **Поддержка форматов** | PDF, DOCX, TXT, RTF, HTML, EPUB, MD, изображения (с OCR) |
| **Гибридный поиск** | BM25 + векторный поиск |
| **LLM генерация** | Mistral (локально) или OpenAI |
| **Переранжирование** | Cross-encoder для улучшения качества |
| **Мультимодальность** | Извлечение текста из изображений |
| **API** | FastAPI + Swagger документация |
| **UI** | Gradio веб-интерфейс |
| **Масштабирование** | Kubernetes + горизонтальное масштабирование |

##  Технологии

- **Backend**: FastAPI, Python
- **Поиск**: BM25 (rank-bm25), FAISS
- **Эмбеддинги**: SentenceTransformers (multilingual-e5-large)
- **LLM**: Mistral 7B (локально) или OpenAI GPT-3.5/4
- **OCR**: Tesseract
- **Frontend**: Gradio 6
- **MLOps**: Docker, Kubernetes, Redis
